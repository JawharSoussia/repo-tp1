    Comprendre avant de taper

    Git en quelques minutes

    Un logiciel de gestion de versions garde la trace de chaque modification d'un projet : qui a changé quoi, quand et pourquoi. On peut revenir en arrière, comparer deux versions, et travailler à plusieurs sans écraser le travail des autres.

    Sur votre machine

    Git

    Un logiciel installé sur votre ordinateur. Il fonctionne sans connexion Internet et range tout l'historique dans un dossier caché nommé .git.

    En ligne

    GitHub

    Un site qui héberge des dépôts Git. Il sert de point de rendez-vous pour l'équipe. GitLab et Bitbucket jouent le même rôle : Git reste le même partout.

    Pourquoi en DevOps

    Le point de départ

    Tests automatiques, déploiements, revues de code : tout part d'un dépôt Git. Savoir l'utiliser proprement est la première compétence du métier.
